# 🧮 Calculadora_IMC  
Aplicação web para cálculo de IMC (Índice de Massa Corporal)

---

## 📌 Funcionalidades

- 🔹 Cálculo automático do IMC  
- 🔹 Classificação de saúde baseada no resultado  
- 🔹 Tabela informativa de referência  
- 🔹 Validação de inputs com Regex  
- 🔹 Feedback visual com cores dinâmicas  
- 🔹 Animações e interações de interface  
- 🔹 Layout responsivo  

---

## 🚀 Tecnologias Utilizadas

- React JS  
- JavaScript (ES6+)  
- CSS3  
- Hooks (`useState`)  

---

## 📂 Como Usar

```bash
# Clone este repositório
git clone https://github.com/DevsAlves/Imc_react.git

# Instale as dependências
npm install

# Inicie o projeto
npm run dev
```
